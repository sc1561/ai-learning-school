# منصة التعلم والمسابقات المدرسية

نموذج أولي عربي باتجاه RTL للتعلم الذاتي والمسابقات المباشرة. يستخدم FastAPI وReact وPostgreSQL؛ التوقيت وحساب النقاط يتحقق منهما الخادم. يتضمن ثلاثة دروس تجريبية مستلهمة من المواد التدريبية المرفقة (بايثون، منهجيات التطوير، UI/UX)، وليست نسخًا كاملة من المواد.

## التشغيل

1. ثبّت Docker Desktop وDocker Compose.
2. انسخ `.env.example` إلى `.env`، وغيّر `SECRET_KEY` لقيمة طويلة عشوائية.
3. شغّل `docker compose up --build` من جذر المشروع.
4. افتح http://localhost:5173 والوثائق http://localhost:8000/docs.
5. أنشئ حساب طالب من الواجهة. لإتاحة إنشاء المسابقات، حدّث دور حساب معلّم موثوق يدويًا في قاعدة البيانات إلى `teacher`؛ التسجيل العام ينشئ حسابات طلبة فقط.

## شجرة المشروع

```
backend/app/          قاعدة البيانات، المصادقة، API، المسابقات وWebSocket
backend/tests/        اختبارات التحقق
frontend/src/         واجهة عربية تفاعلية
compose.yaml          تشغيل الواجهة والخادم وPostgreSQL
.env.example          متغيرات البيئة النموذجية
docs/                 البروتوكول ومخطط البيانات
```

## قواعد المسابقة

- وقت البداية شامل والنهاية غير شاملة، ويحسبهما الخادم بتوقيت UTC؛ أدخل أوقات ISO 8601 مع المنطقة الزمنية.
- الإجابة مرة واحدة لكل سؤال ومسابقة؛ 20 نقطة للإجابة الصحيحة، و10 للسؤال التدريبي. يسجل مصدر النقطة في `point_events` لمنع تكرارها.
- الاتصال اللحظي يعرض الحالة والوقت المتبقي ولوحة نتائج المسابقة كل ثانية، ويغلق بعد نهايتها. الخادم يتحقق من الوقت عند استلام الإجابة أيضًا.
- لوحة الشرف العامة تعتمد على النقاط المخزنة بقاعدة البيانات؛ Redis غير مطلوب لهذا الحجم، ويمكن إضافته لاحقًا كذاكرة مؤقتة عند قياس الحاجة.

## حدود النسخة الأولية

تستخدم الجداول إنشاءً مباشرًا عند بدء التشغيل؛ قبل نشر عام أضف migrations، تحديد معدل الطلبات، مراقبة، آلية إعادة تعيين كلمات المرور، موافقة وإدارة حسابات الطلبة، وسياسة حفظ بياناتهم. لا تضع أسماء طلبة حقيقية أو كلمات مرور في المستودع. GitHub Pages يستضيف الواجهة فقط، ويتطلب استضافة منفصلة للخادم وقاعدة البيانات، مع ضبط `VITE_API_URL` و`CORS_ORIGINS` وHTTPS. الاتصال اللحظي الحالي يحدّث كل ثانية من قاعدة البيانات، ويحتاج بثًا مركزيًا عند التوسع إلى أعداد كبيرة.
