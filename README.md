# منصة التعلم والمسابقات المدرسية

منصة عربية تعمل على GitHub Pages مباشرة: دروس قصيرة، حساب نقاط محلي، وتحدٍ موقوت لمدة ثلاث دقائق. لا تحتاج Docker أو خادمًا أو قاعدة بيانات.

## الاستخدام

افتح رابط GitHub Pages بعد تفعيل النشر من إعدادات المستودع (Settings → Pages → Build and deployment → GitHub Actions). ينشر ملف `.github/workflows/pages.yml` الواجهة عند تحديث الفرع `main`.

اختر اسم الطالب من الصفحة، وابدأ الدروس أو التحدي المحلي. يمكن إدخال أسماء كثيرة من قسم **إدارة الجهاز**، كل اسم في سطر. تُحفظ الأسماء والنقاط في `localStorage` على المتصفح نفسه. نزّل نسخة احتياطية من داخل المنصة إذا أردت نقل النتائج إلى جهاز آخر، ثم استوردها هناك.

## حدود النسخة المحلية

- اختيار الاسم ليس تسجيل دخول آمنًا؛ يستطيع أي مستخدم لهذا الجهاز اختيار أي اسم وتعديل البيانات من أدوات المتصفح.
- المسابقة موقوتة لكل ملف محلي على حدة؛ لا توجد غرفة مشتركة أو نتائج لحظية موحدة بين الأجهزة.
- النقاط لا تُرفع إلى GitHub ولا تتزامن بين الأجهزة؛ مسح بيانات المتصفح قد يمحوها.
- لا تُدخل بيانات طلاب حساسة أو كلمات مرور في المستودع أو في أسماء الحسابات. احتفظ بنسخة النتائج في مكان آمن.

## التطوير

```bash
cd frontend
npm ci
npm run dev
```
