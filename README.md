# منصة التعلم والمسابقات المدرسية

منصة عربية تعمل على GitHub Pages مباشرة: دروس قصيرة، حساب نقاط محلي، وثلاثة اختبارات ذكية متدرجة. لا تحتاج Docker أو خادمًا أو قاعدة بيانات.

## الأكاديمية

من الشريط الجانبي افتح **الأكاديمية** لاستكشاف ثلاثة أقسام: التطبيقات المعززة بالذكاء الاصطناعي، الأمن السيبراني، ومختبر التقاط العلم. داخل كل قسم مسارات، ودروس بمثال ونشاط وسؤال تحقق، وتحديات تدريبية في قسم التقاط العلم. تبقى رحلة مشروع مساعد المدرسة الذكي والاختبارات الأصلية متاحة. يمنح إكمال الدرس الجديد 20 نقطة، ويمنح التقاط العلم النقاط المعروضة على التحدي مرة واحدة لكل ملف طالب على هذا الجهاز.

### إضافة مسار جديد

الطريقة الأسهل للمحتوى المنشور: حرّر `frontend/src/academyCatalog.json` وأضف مسارًا إلى `tracks` داخل القسم المناسب ثم ارفع التعديل إلى `main` ليُنشر تلقائيًا. كل درس يحتاج `id` فريدًا و`title` و`concept` و`example` و`task` و`question` وثلاث `choices` ورقم الإجابة `correct` (0 أو 1 أو 2) و`explain`. ويمكن أن يحوي المسار `challenges`؛ لكل تحدٍّ `id` فريد و`title` و`prompt` و`hint` و`flag` بصيغة `SCHOOL{answer}` و`points` و`explain`. استعمل معرّفات إنجليزية صغيرة وأرقامًا وشرطات فقط، ولا تغيّر المعرّفات المنشورة كي لا ينقطع سجل الإنجازات السابق.

للتجربة دون تعديل المستودع، استورد من صفحة **الإدارة** ملف JSON بالشكل التالي؛ سيظهر المسار على هذا المتصفح فقط ويمكن تصديره بعد التجربة. لن يظهر على الأجهزة الأخرى حتى تضيفه إلى ملف المحتوى المنشور في GitHub:

```json
{"tracks":[{"areaId":"cyber","id":"safe-starter","title":"تجربة الأمان","level":"تمهيدي","description":"تدريب قصير","lessons":[{"id":"safe-starter-01","title":"تجربة أولى","concept":"فكرة الدرس","example":"مثال واضح","task":"نشاط للطالب","question":"ما الإجابة الصحيحة؟","choices":["خيار أول","خيار ثانٍ","خيار ثالث"],"correct":0,"explain":"سبب الإجابة"}]}]}
```

أقسام `areaId` الحالية هي `ai` و`cyber` و`ctf`. التحديات هنا ألغاز تعليمية داخل ملفات الموقع، لذلك الإجابات قابلة للاطلاع في المصدر؛ استخدم خادمًا مستقلًا للتحقق والتحكيم إذا أردت منافسة رسمية مشتركة أو جوائز.

## خصائص الاختبارات

- 90 سؤالًا أصليًا: 30 سؤالًا في كل مستوى.
- مستويات سهل ومتوسط وصعب، بمدة 15 دقيقة لكل مستوى.
- درجات نجاح متدرجة: 60% و70% و80%.
- معلّم ذكي يقدم تلميحًا مرتبطًا بالسؤال دون كشف الإجابة.
- جدول للتنقل بين الأسئلة وتمييز الأسئلة للرجوع إليها.
- حفظ المحاولة تلقائيًا على الجهاز واستكمالها بعد تحديث الصفحة.
- تحليل النتيجة حسب الموضوع وربطها بالنقاط ولوحة الشرف.
- تصدير جميع نتائج الجهاز إلى CSV متوافق مع Excel.

## الاستخدام

افتح رابط GitHub Pages بعد تفعيل النشر من إعدادات المستودع (Settings → Pages → Build and deployment → GitHub Actions). ينشر ملف `.github/workflows/pages.yml` الواجهة عند تحديث الفرع `main`.

من **إدارة الجهاز** يمكنك اختيار ملف `studentData.json` محليًا؛ يُقرأ بنظام «الشعبة → قائمة الأسماء» لتختار الشعبة والطالب من الواجهة. لا يُرفع ملف الأسماء إلى المستودع. يمكنك كذلك إضافة أسماء يدويًا. تُحفظ الأسماء والنقاط في `localStorage` على المتصفح نفسه. نزّل نسخة احتياطية من داخل المنصة إذا أردت نقل النتائج إلى جهاز آخر، ثم استوردها هناك. لاستعمال القائمة على عدة أجهزة، استورد الملف على كل جهاز على حدة.

## حدود النسخة المحلية

- اختيار الاسم ليس تسجيل دخول آمنًا؛ يستطيع أي مستخدم لهذا الجهاز اختيار أي اسم وتعديل البيانات من أدوات المتصفح.
- الاختبارات موقوتة لكل ملف محلي على حدة؛ لا توجد غرفة مشتركة أو نتائج لحظية موحدة بين الأجهزة.
- النقاط لا تُرفع إلى GitHub ولا تتزامن بين الأجهزة؛ مسح بيانات المتصفح قد يمحوها.
- لا تُدخل بيانات طلاب حساسة أو كلمات مرور في المستودع أو في أسماء الحسابات. احتفظ بنسخة النتائج في مكان آمن.
